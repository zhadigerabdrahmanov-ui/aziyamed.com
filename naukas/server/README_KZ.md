# Наукас жолдамасы — жергілікті серверге орнату (Linux, тек емхана желісі)

**Не өзгереді:** сайт (HTML) пен дерекқор (Firebase орнына) енді емхананың өз серверінде. Деректер (РПН, жоспарлар, жолдамалар, хабарлама журналы) емханадан шықпайды.

Сервер — бір файл (`server.js`), тек Node.js керек, Firebase-пен бірдей REST форматта жұмыс істейді. Сондықтан қосымшаның кодына тек екі мекенжай ауыстырылады (мұны `build.js` өзі істейді).

## Папкадағы файлдар
| Файл | Не үшін |
|---|---|
| `server.js` | сервер (сайт + дерекқор) |
| `app/index.html` | дайын қосымша (v87, жергілікті мекенжаймен) |
| `vendor/` | Excel кітапханалары (интернетсіз істеуі үшін) |
| `migrate.js` | Firebase-тегі деректерді көшіру |
| `build.js` | жаңа HTML нұсқасын серверге дайындау |
| `Dockerfile`, `docker-compose.yml` | Docker арқылы іске қосу |
| `naukas.service` | Docker-сыз (systemd) іске қосу |
| `backup.sh` | күнделікті сақтық көшірме |

## 1-қадам. Серверді дайындау
Ubuntu/Debian серверіне Docker орнатыңыз (Docker-сыз жолда — Node.js 20+):
```
curl -fsSL https://get.docker.com | sudo sh
```
Серверге бұл папканы (`naukas_local`) `/srv/naukas` деп көшіріңіз (WinSCP, `scp` немесе флешка).

Серверге **тұрақты IP** беріңіз (роутерде «DHCP reservation» немесе серверде статикалық IP), мысалы `192.168.1.50`.

## 2-қадам. Іске қосу
```
cd /srv/naukas
sudo docker compose up -d --build
curl http://localhost/health      # "ok" шығуы керек
```
`docker-compose.yml` ішіндегі `ALLOW_PREFIX` — тек сіздің желіңіздің IP-ін рұқсат етеді (`192.168.` не `10.` өзіңіздің желіге сәйкес өзгертіңіз).

## 3-қадам. Деректерді Firebase-тен көшіру
Сервер қосулы кезде (серверде немесе кез келген компьютерде, Node.js 18+):
```
node migrate.js
```
Ол Firebase-тің барлық бөлімін (`rpn_baza`, `rpn_edits`, `vacc`, `scr`, `prf`, `dispan`, `dsp`, `staff`, `referrals`, `test`, `notif`, `bot`…) өз серверіне көшіреді. Алдымен **жұмыс уақытынан тыс** жасаңыз, көшіру кезінде ешкім жаңа дерек енгізбесін. Қайта іске қоссаңыз, қайта жазады (қауіпсіз).

## 4-қадам. Тексеру
Емхана желісіндегі браузерде `http://192.168.1.50/` ашыңыз → әдеттегідей кіріңіз. Алдымен бір-екі адаммен: РПН тізімі ашылады ма, жолдама жіберіледі ме, Excel жүктеледі ме.

Бәрі дұрыс болған соң ғана қызметкерлерге жаңа мекенжайды беріңіз. Ескі GitHub нұсқасын бірден өшірмеңіз: Firebase-тегі деректер қалады, бірақ **екі жерде бір мезгілде жұмыс істемеңіз** (дерек бөлініп кетеді).

## Сақтық көшірме (міндетті)
- Сервер деректерді `data/db.json` + `data/journal.ndjson` ішінде сақтайды; қуат өшсе де жоғалмайды (сынақтан өтті).
- Күнделікті көшірме: `sudo crontab -e` → `30 2 * * * /srv/naukas/backup.sh` (30 күн сақталады). `BACKUP_DIR` арқылы көшірмені **басқа дискіге/компьютерге** жіберіңіз — бір диск бұзылса бәрі жоғалмауы үшін.
- Қалпына келтіру: сервер тоқтатылып, `db.json` қойылады, `journal.ndjson` өшіріледі.

## Жаңа нұсқаны орнату (әр жаңартуда)
```
node build.js жаңа_файл.html        # app/index.html жаңарады
sudo docker compose up -d --build
```
Сайттың жаңа нұсқасын жүктегенде дерекқорға тиіспейді.

## Назар аударатын жайттар
1. **Сайт HTTP арқылы ашылады** (LAN-да HTTPS жоқ). Сондықтан «📋 мәтінді көшіру» батырмасы кейбір браузерде автоматты көшірмейді, терезе шығып, мәтінді қолмен көшіресіз. Қалғаны жұмыс істейді. HTTPS керек болса, кейін ішкі сертификат қосамыз.
2. **WhatsApp-бот** (`whatsapp_bot/worker.js`) интернеттегі Cloudflare-де жұмыс істейді де, емхананың ішкі серверіне жете алмайды. Ботты қолданғыңыз келсе, дерекқорсыз жеңіл нұсқа керек (немесе тек бот үшін бөлек шағын канал). Ботты бастамай тұрып осыны айтыңыз, шешемін.
3. **Қауіпсіздік:** сервер тек ішкі желіге ашылуы керек. Роутерде 80 портты интернетке **ашпаңыз**. Деректерге кіруге логин жоқ (бұрынғы Firebase сияқты), қорғаныс — желі шектеуі. Қосымша: сервер ОЖ-сінде `ufw allow from 192.168.0.0/16 to any port 80`.
4. Сервер 1 процесте жұмыс істейді; жүздеген қызметкерге бұл жеткілікті. Деректер қолданыстағы көлемде (~20–50 МБ) жедел жадта тұрады.
5. Интернетсіз де істейді (Excel кітапханалары `vendor/`-да). Тек сыртқы сілтемелер (medelement.com, WhatsApp) интернетті қажет етеді.
