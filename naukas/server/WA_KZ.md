# WhatsApp Business API (Cloud API) — жаппай хабарлама жіберу

Сервердегі `/wa` эндпоинті Meta-ның ресми WhatsApp Cloud API арқылы хабарлама жібереді.
Қосу үшін `data/wa.json` файлын жасау керек (деректер папкасында, дерекқорға түспейді).

## 1. Meta жағында не керек (бір рет)

1. https://business.facebook.com — Meta Business аккаунты (емхана атынан).
2. https://developers.facebook.com → «Create App» → тип **Business** → «WhatsApp» өнімін қосу.
3. WhatsApp → API Setup: емханың нөмірін қосып, SMS-кодпен растау.
   Осы беттен **Phone number ID** көшіріп алыңыз.
4. Тұрақты токен: Business Settings → System Users → жаңа System User (Admin) →
   «Generate token» → қолданба таңдаңыз, рұқсаттар: `whatsapp_business_messaging`, `whatsapp_business_management`.
   Токенді **ешкімге көрсетпей** `wa.json`-ға салыңыз.
5. Business verification (Meta тексеруі) өтпесе, тәулігіне 250 әртүрлі нөмірге ғана жіберуге болады;
   өткен соң лимит 1 000 → 10 000 → 100 000 дейін өсе береді.
6. Төлем тәсілін қосыңыз (Billing) — әр 24-сағаттық «утилита» диалогы ақылы (Қазақстан үшін шамамен 0,02–0,05 $).

## 2. Шаблондарды жасау (міндетті)

Емхана өзі бастаған хабарлама тек **бекітілген шаблонмен** жіберіледі.
WhatsApp Manager → Message templates → Create template:

| Атауы | Санаты | Тілі | Мәтіні (Body) |
|---|---|---|---|
| `naukas_habar_kk` | Utility | Kazakh (kk) | `{{1}}` |
| `naukas_habar_ru` | Utility | Russian (ru) | `{{1}}` |

Шаблон денесі — бір айнымалы `{{1}}`. Қосымшаның дайын мәтіні сол айнымалыға толық салынады
(сервер жаңа жолдарды « | » белгісіне ауыстырады — Meta айнымалыда жаңа жолға рұқсат бермейді).
Meta бос `{{1}}`-ді қабылдамауы мүмкін — онда былай жазыңыз:

- kk: `«Азия мед-МО» емханасы. {{1}}`
- ru: `Поликлиника «Азия мед-МО». {{1}}`

Үлгі (sample) ретінде кез келген хабарлама мәтінін көрсетіңіз. Бекіту әдетте бірнеше минуттан 24 сағатқа дейін.

## 3. data/wa.json

```json
{
  "enabled": true,
  "provider": "cloud",
  "token": "EAAG....................",
  "phoneNumberId": "123456789012345",
  "apiVersion": "v21.0",
  "templates": { "kk": "naukas_habar_kk", "ru": "naukas_habar_ru" },
  "dailyCap": 1000
}
```

Сынақ режимі (ешнәрсе жібермейді, тек журналға жазады):

```json
{ "enabled": true, "provider": "log", "dailyCap": 1000 }
```

Файлды өзгерткен соң серверді қайта іске қосудың қажеті жоқ — әр сұраныста оқылады.
Тексеру: `http://СЕРВЕР:8088/wa/status` → `{"enabled":true,"provider":"cloud",...}`.

## 4. Қосымшада қалай жұмыс істейді

- **Хабарлама** терезесінде (медбике/регистратура/эксперт) жасыл блок «📤 WhatsApp Business API — жаппай жіберу»:
  қазіргі сүзгідегі (мерзім, түр, участок, тіл) нөмірі бар, әлі жіберілмеген барлық пациентке бір батырмамен жібереді.
  4 параллель ағын, прогресс-жолақ, «Тоқтату» батырмасы; 5 қатар қате немесе лимит → автоматты тоқтайды.
  Сәтті жіберілгендер `notif/<ИИН>` ішінде «WhatsApp API · <кім>» деп белгіленеді.
- **Автоматты жіберу** блогында канал таңдауы: SMS немесе WhatsApp (API). Күн сайын белгіленген сағатта өзі жібереді.
- Нөмір форматы: 7XXXXXXXXXX (сервер өзі тазалайды). Пациент WhatsApp-та жоқ болса — қате (131026) қайтады, келесіге өтеді.

## 5. Ескертулер

- Токен мен `wa.json` — құпия файл, тек серверде сақтаңыз.
- Хабарламаны алушы «Жауап беру» арқылы жазса, 24 сағат ішінде еркін мәтінмен жауап беруге болады (бұл қосымшада қарастырылмаған, WhatsApp Business қосымшасы арқылы жауап беріңіз — сол нөмірді сонда да қолдануға болады ТЕК Cloud API-ға көшірмеген жағдайда; Cloud API-ға қосылған нөмір кәдімгі WhatsApp қосымшасында жұмыс істемейді).
- Жеткізу статусын (delivered/read) көру үшін webhook керек — қажет болса кейін қосамыз.
